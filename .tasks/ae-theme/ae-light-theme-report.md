## Part B：SCENE 亮色背景视觉评估

### 评估方法论

从深色切换到亮色背景，核心影响：

1. **对比度反转** — 深底上手机靠"亮屏 vs 暗底"出效果；亮底上手机靠**阴影 + 机身颜色**出效果
2. **Purple 机身优势** — 紫色机身在浅紫底上是**同色系协调**，但需要足够深度的阴影层才不会"被吃掉"
3. **文字可读性** — 原白字在亮底完全不可读，改 #5B21B6 后对比度 ≥ 7.8:1（WCAG AAA）
4. **镜头动态** — 慢推/慢摇在亮底更显"精致高级感"；快速旋转在亮底容易"晃"
5. **屏幕数量** — 双屏/多屏镜头在亮底需要更强的阴影分隔，否则两台手机会"黏在一起"

### 总建议

**推荐"微调方案"**：保持 SCENE_01 / 05 / 13，将 SCENE_10 → SCENE_09。理由：

1. SCENE_10 的双屏对比在深色下靠"暗底亮屏"反差出效果，亮底下这个反差消失了
2. SCENE_09 的 10s 单屏长镜在亮底下质感提升明显，更适合展示教师端信息密集页面
3. 如果叙事上必须有"双屏对比"，则保持 SCENE_10 + 在 Part A 脚本后手动为 SCENE_10 的两台手机添加更强的 Drop Shadow 效果补偿

**如果想做 5 个 SCENE（扩展到 ~40s）**：加入 SCENE_25（PreComp 双屏，8s），放在 SCENE_09 之后、SCENE_13 之前，展示"学生问 × 教师知识库"构图。

### 现状

### 渲染方式：用户在 AE 中手动执行

#### 步骤 1：运行改造脚本
1. 打开 AE 模板 `.aep` 文件
2. `File > Scripts > Run Script File...` → 选 `.tasks/ae-light-theme.jsx`
3. 等待执行完毕，查看弹窗日志确认无报错

#### 步骤 2：占位截图导入（可选）
现有教师端截图可直接拖入对应 SCENE 的 `Screen 01` 合成：

> 如果嫌麻烦，保持原占位或用纯灰色 #E5E7EB solid 即可——这次只验证亮色主题效果。

#### 步骤 3：渲染预览
1. 在项目面板找到 `HD` 合成（1920×1080）
2. `Composition > Add to Render Queue`
3. Output Module: H.264 / mp4
4. Output To: `F:\Documents\code\yixiaoguan-v2\.tasks\preview-light-theme-v1.mp4`
5. 点 Render

> **如果 HD 合成渲染整个 251s 太长**：先在时间轴上设 Work Area（B / N 快捷键）仅覆盖 SCENE_01+05+09/10+13 的时间范围，再渲染。
