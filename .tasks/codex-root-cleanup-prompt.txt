## 执行步骤

### 1. 创建归档目录

```powershell
New-Item -ItemType Directory -Path "C:\Users\Administrator\Documents\code\yixiaoguan-v2\.archive\2026-04" -Force
```

并在 `.archive/2026-04/README.md` 写一段说明：

```markdown
# .archive/2026-04/

本目录归档了 2026 年 4 月 sprint 期间的临时报告、试验脚本，避免污染主仓根目录。
归档保留在 git 历史里以便追溯，但不再活跃维护。

如需查看具体内容，请直接打开对应 `.md` / `.py` 文件。
```

### 2. 用 `git mv` 归档（保留 git 历史）

逐个执行（不要批量 `git add` 然后 `git mv`，逐个保证 history 链不断）：

```bash
cd C:\Users\Administrator\Documents\code\yixiaoguan-v2
git mv s1-design-tokens-report.md .archive/2026-04/
git mv s2-e-smoke-test.md .archive/2026-04/
git mv s2-final.md .archive/2026-04/
git mv s2-retest.md .archive/2026-04/
git mv s3-deploy-test.md .archive/2026-04/
git mv s3-kb-migrate.md .archive/2026-04/
git mv bailian.txt .archive/2026-04/
git mv test_login.py .archive/2026-04/
git mv ws_test.py .archive/2026-04/
```

> 注意：上面文件只在**主仓 master**有 tracked 副本时才能 `git mv`。如果某个文件实际是 untracked（git 没追踪过），跳过 `git mv`，改用 `Move-Item` 把物理文件挪过去。
