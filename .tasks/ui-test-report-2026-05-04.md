## 🐛 UI Bug（建议修复）

### Bug 1: 首页问候语硬编码为"下午好"

- **文件**: `apps/student-app/src/pages/home/index.vue` 第 17 行
- **现象**: 凌晨 4 点仍显示 "下午好，彭一诺"
- **原因**: 模板中写死了 `下午好`，没有根据时间动态计算
- **截图**: `06-home-top.png`
- **修复**: 用 computed 属性根据 `new Date().getHours()` 返回 "早上好/上午好/下午好/晚上好"
- **影响**: 低风险，纯展示文案

### Bug 2: `border-bottom` 幽灵类名

- **文件**: `apps/student-app/src/pages/services/index.vue` 第 121 行
- **现象**: 个人日程 `<view>` 上使用了 `class="personal-item border-bottom"`，但 `.border-bottom` 在组件样式和全局样式中均未定义
- **影响**: 目前无明显视觉问题（两个列表项之间仍有自然间距），但属于"死代码"
- **修复**: 删除无效类名 或 补定义为 `border-bottom: 1px solid $outline-variant`

## ⚠️ 轻微问题（可选修复）

### Issue 1: 登录页空提交 toast 位置

- **现象**: 空字段提交时 `uni.showToast({ title: '请输入学号', icon: 'none' })` 的弹出位置在 H5 模式下略显突兀（浮在密码输入框上方）
- **截图**: `02-login-empty-submit.png`
- **评估**: uni-app 原生 Toast 行为，难以自定义位置。**建议不动**

### Issue 2: 窄屏 320px 校园服务网格文字拥挤

- **现象**: iPhone SE (320px) 下 4 列校园服务网格图标和标签非常紧凑
- **截图**: `31-narrow-services.png`
- **评估**: 320px 设备占比极低。当前布局仍可用，标签仍可读。**建议不动**

### Issue 3: 窄屏 320px 首页 Bento 卡片文字换行

- **现象**: "AI 智能助手" 文字在 320px 下换行为 "AI 智能\n助手"，描述文字也被截断
- **截图**: `30-narrow-home.png`
- **评估**: 窄屏下属正常换行，不影响功能。**建议不动**

## 💡 建设性建议（不属于本阶段）

1. **首页「常用服务」可自定义** — 当前 4 项硬编码，后续可做拖拽排序或收藏
2. **搜索功能** — 首页搜索栏目前只是跳转 AI 问答，可考虑加搜索历史/热词功能
3. **深色模式** — 整体 UI 已有 MD3 token 基础，后续可考虑 dark mode
4. **无网络状态** — 目前没有离线/弱网的 UI 提示，可增加 Empty State
5. **Coming Soon Sheet** — 消息通知/系统设置的 Sheet 只显示"敬请期待"，可加预期上线时间
6. **Profile 头像上传** — 当前显示首字母 fallback，后续可加上传头像功能
