#### Test 1: 学生登录成功

#### Test 3: 学生提交问题给辅导员

#### Test 5: cleanup（不算入 pass/fail，best-effort）

- 不要让 cleanup 失败破坏整体测试结果

### 3. 选择器策略

学生/教师 H5 是 uniapp Vue 3 编译后产物。selector 优先级：

1. **文本匹配**：`page.locator("text=登录")`、`page.get_by_role("button", name="发送")`
2. **placeholder**：`page.get_by_placeholder("请输入学号")`
3. **CSS class**：作为 fallback，避免依赖 uniapp 自动生成的随机 class
4. **重要**：等待元素时用 `wait_for(state="visible", timeout=10000)`

如果你不确定真实 DOM 结构，**第一步**先用 chromium headed mode 短暂打开学生登录页 + 用 `page.content()[:3000]` 打印一段 HTML 到日志，看到真实 markup 后再写 selector。这一步只在你不确定时做，且 timeout=15s。
