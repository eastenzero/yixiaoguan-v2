## 配音 A/B 测试候选（A5 任务）

| API | 优势 | 劣势 | 价格 |
|---|---|---|---|
| **阿里云语音合成（CosyVoice）** | 中文最自然，本土化，校园语境贴合 | 国内服务，需 API key | 起步免费额度 |
| **火山引擎语音合成** | 抖音级别中文质感 | 产品宣传调性，可能过亮 | 按字符计费 |
| **Azure Neural Speech** | 中文质量很好，海外标准 | 需 Azure 账号 | 起步免费额度 |
| **ElevenLabs** | 英文最佳，中文一般 | 中文偶有不自然 | 按字符计费 |

**A/B 测试方案**：
1. 选 D2 数据看板段（200 字 / 20s）作为对比样本
2. 4 家各跑一遍 → 你盲听 → 投票
3. 选定一家后跑全文 644 字 → 输出 `.tmp/demo-video/narration/full.mp3`

## 关于 BGM 选型

- **风格**：Lo-fi corporate inspirational（轻电子 + 钢琴 / 弦乐铺底）
- **节奏**：80-100 BPM，与配音字密度同步
- **音量**：配音段 BGM 衰减 -18dB（不抢人声）
- **候选库**：Epidemic Sound / Artlist / YouTube Audio Library
- **建议曲名搜索词**：`tech inspirational`、`corporate uplifting`、`mellow tech`
