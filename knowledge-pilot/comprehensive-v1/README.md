# 医小管知识库·全面回答版 v1

这是一个独立影子版，不覆盖当前线上的严谨版。目标是在不编造校内细则的前提下，让回答更具体、更全面、更能解决学生的实际问题。

## 核心改变

- 从“缺一项就拒答”改为“分层回答”：国家政策、山东省政策、学校通知、学院执行分别标注。
- 先给结论和实际操作，再说例外、时效和待核实点。
- 当年通知缺失时，可以说明现行上位政策和山一大往年办理流程，但明确标记“历史参考”。
- 不把某个学院的门槛套用到其他学院；可以将它作为办理流程示例。
- 回答附加参考资料默认展示 3–6 条，最多 8 条，实际命中来源优先。

## 文件

- `answer-contract.md`：全面回答版的系统提示词与输出契约。
- `source_registry.json`：国家、山东省、学校及学院的官方来源注册表。
- `scholarship-guide.md`：奖学金国家/省/学校/学院分层知识卡。
- `retrieval-policy.json`：召回、重排、时效与来源多样性规则。
- `evaluation.jsonl`：全面回答版的验收问题。
- `github-design-notes.md`：对开源 RAG 案例的取舍。
- `comparison-preview.md`：严谨版与全面版的预览对比。
- `shadow-release.json`：不覆盖生产版的发布与回滚记录。
- `validate_pack.py`：零依赖知识包校验器。

## 发布原则

1. 首先以新 Dify 工作流/影子数据集运行，不改动线上严谨版。
2. 使用 `evaluation.jsonl` 对比回答完整度、具体性、来源可追溯性。
3. 用户选定后再切换默认工作流；原版工作流 ID 作为回滚点保留。
