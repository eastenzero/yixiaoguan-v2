# 医小管知识库·全面回答版 v2

v2 在 v1 的“国家—山东省—学校—学院”事实分层上，重点解决三个问题：

1. 回答太短，只有审核口径，没有办事帮助。
2. 奖学金只按资金来源粗分，奖项之间的金额、排名、困难认定、互斥关系和申请流程没有分开。
3. 段落节奏不好，结论、细则、操作和风险挤在一起。

## v2 回答闭环

`直接结论 → 奖项定位 → 具体条件 → 你现在怎么办 → 需核实的一两点 → 参考资料 → 继续追问`

## 文件

- `answer-contract.md`：长回答、分段和继续追问契约。
- `interaction-benchmark.md`：其他高校智能助手的可复用交互经验。
- `scholarship-matrix.json`：每个奖项的独立事实卡。
- `scholarship-longform.md`：奖学金长回答标准示例。
- `evaluation.jsonl`：专门检查分层、段落、互斥与办事可用性。
- `shadow-release.json`：v1/v2/线上严谨版的回滚关系。
- `validate_v2.py`：零依赖校验。

v2 继承 `../comprehensive-v1/source_registry.json` 的官方来源，不重复养两份来源表。
