## 待修复

### #1 JWT 过期无续签，多终端登录冲突
- **发现日期**: 2026-05-01
- **现象**: 一个终端登录后，其他终端显示「登录已过期」
- **根因**: JWT 有效期 24h 且无 refresh token；多标签页 localStorage 共享但内存 token 不同步
- **临时处理**: JWT_EXPIRE_HOURS 已从 24 改为 168（7 天） ✅
- **长期方案**: 
  - 后端新增 `POST /api/auth/refresh` 端点
  - 前端 401 拦截器：先尝试用 localStorage 最新 token 重试，再尝试 refresh，最后才跳登录页
- **状态**: 🟡 临时方案已上线，长期方案待实施
