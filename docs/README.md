## 使用约定

1. **新需求一律写进 `requirements/` 目录**，不要只在聊天中讨论
2. 每个需求文档顶部标注**来源、日期、状态**
3. 状态使用：`草案` → `已确认` → `开发中` → `已实现` → `已废弃`
4. 与 AI 讨论出的结论，当场就记录到对应文档中
5. 不创建重复文档——先检查是否已有相关文档
