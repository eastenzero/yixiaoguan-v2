## 一页纸核心结论

| 项目 | 决策 | 关键数字 |
|------|------|---------|
| 项目定位 | 比赛背书 + 学院内测辅佐 | 不做全校真实推广（1 年内） |
| 部署架构 | Dify 保持，不自建 | 避免自研 RAG 浪费时间 |
| 资源（学院级） | 2 vCPU + 4GB + 5Mbps | 月成本 ≤¥250 |
| 资源（全校级，未来） | 2 × 4C8G + Redis + CDN | 月成本 ¥800-1500 |
| 主模型 | **qwen-plus**（TX 已决） | 成本降至 qwen-max 的 1/5 |
| 超纲问题 | L1 意图分类 + 人设 prompt | 落地见 R06-3 |
| 外部 API | 学院阶段不接，全校级接校园地图 | 不做天气/外卖 |

**关键结论**：**当前方案可在 1 台 2C4G 云服务器上稳定运行，月成本 ≤¥500**（含 API），足够支撑比赛展示 + 学院内测使用。
