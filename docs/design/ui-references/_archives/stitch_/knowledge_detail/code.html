学生电费缴纳指南

person
系统管理员 最后更新于 2023年10月24日 14:30

1. 缴纳方式概述

为方便广大在校学生，学校提供了多种电费缴纳途径。目前支持通过校园一卡通、手机银行以及第三方支付平台（微信/支付宝）进行实时充值。

2. 详细操作步骤

  • 01

    登录校园小程序

    打开“智慧校园”小程序，进入“生活缴费”模块，选择“电费管理”。

  • 02

    绑定宿舍信息

    首次使用需输入所在楼栋和宿舍号进行身份校验与余额查询。

  • 03

    确认并支付

    输入充值金额（单次不少于10元），选择支付方式并完成确认。

3. 注意事项

“系统每日 23:30 至次日 00:30 为结算维护时间，期间无法进行充值，请避开此时段。”

如遇充值成功但电表未及时下发指令的情况，请携带一卡通前往宿舍楼下的自助终端进行补登，或联系后勤保障部服务热线（010-88888888）。
