Teacher Mobile H5 App for 'YiXiaoGuan' (医小管). Tech Stack: Vue 3 (Composition API), Vite, Tailwind CSS 3, Vue Router 4, TypeScript. Branding: MD3 Purple Theme. Screens: 1. LoginView (/login) - Gradient background, white card. 2. DashboardView (/) - Welcome banner, Bento grid stats, pending questions list, quick actions. 3. QuestionsView (/questions) - Filter tabs, question cards with AI confidence progress bars. 4. QuestionDetailView (/questions/:id) - Student info, AI/Teacher/Student chat history, action area (accept/reply). 5. KnowledgeView (/knowledge) - Search, category tabs, knowledge cards. 6. KnowledgeDetailView (/knowledge/:id) - Content view (Markdown style), status-based actions. 7. ProfileView (/profile) - Info card, work stats, settings list with switches. Common Components: TopAppBar (glassmorphism), BottomNavBar (4 tabs).
