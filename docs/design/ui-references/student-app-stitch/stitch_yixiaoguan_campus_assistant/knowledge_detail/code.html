1. 处理原则与初期评估

一旦疑似急性心肌梗死（AMI），应立即启动紧急医疗服务（EMS）。院前处理的核心在于缩短总缺血时间。评估应在患者到达急诊科后的10分钟内完成，包括心电图检查。

  • 持续心电监测，准备除颤。
  • 建立静脉通路，采集血液样本。
  • 吸氧治疗（若SaO2 < 90%）。
  • 镇痛治疗：必要时使用吗啡或芬太尼。

2. 核心诊疗流程 (Pathways)

根据心电图表现将患者分为STEMI和NSTE-ACS。STEMI患者应优先考虑直接经皮冠状动脉介入治疗（PCI）。若预计从首次医疗接触到PCI的时间超过120分钟，且无禁忌症，应考虑溶栓治疗。

info
关键时限 (D2B) 门-球囊时间应控制在 90 分钟以内。院内转运及术前准备需并行执行以节省时间。

3. 药物治疗规范

抗血小板治疗是治疗的基础。所有患者如无禁忌，应立即给予负荷剂量的阿司匹林（150-300mg）和P2Y12受体拮抗剂。

  • 阿司匹林：长期维持剂量为 75-100mg/d。
  • 他汀类药物：无论胆固醇水平如何，均应在24小时内启动高强度他汀治疗。
  • ACEI/ARB：对合并心衰或射血分数下降的患者具有明确获益。

4. 排除标准与禁忌症

在进行再灌注治疗前，必须严格筛查禁忌症，特别是对于溶栓治疗。既往脑出血史、近期大手术史或活动性出血均属于绝对禁忌。
