# 新对话修复交接说明

建议在新对话中从 `ISSUE-001` 开始。实时通信是工单处理和双端响应的基础，先修它可以让后续测试更可信。

## 推荐第一条新对话提示

请从 `docs/audit-issues-2026-06-20/ISSUE-001-realtime-ws-centrifugo.md` 开始修复实时通信问题。先读取该目录的 README 和 ISSUE-001，确认线上/本地配置差异，然后实现修复并用浏览器双端验证学生呼叫、教师接单、教师回复、学生实时收到。

## 修复原则

- 每次只修一个 issue，避免多个系统同时变动。
- 修复前先复现，修复后用浏览器或接口做最小闭环验证。
- 涉及线上配置时先做只读确认，再明确需要改动的文件或服务器配置。
- 不要回滚用户已有改动。
