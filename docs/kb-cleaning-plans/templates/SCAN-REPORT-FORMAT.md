# KB 扫描报告输出格式

对每个扫描的文件，输出一行表格行：

```
| 文件名 | 保留/丢弃 | 分类 | 信息摘要 | 质量 |
```

字段说明：
- **文件名**：不含路径，仅文件名
- **保留/丢弃**：二选一。丢弃时在摘要列注明原因（如"纯新闻"、"已过期"、"纯导航"、"无实质内容"）
- **分类**：C01-C12 编号（见 SCREENING-CRITERIA.md），丢弃的文件也标注最接近的分类
- **信息摘要**：一句话概括核心内容（20字以内）
- **质量**：高/中/低
  - 高：信息完整、结构清晰、可直接入库
  - 中：信息有价值但需要补充或重新组织
  - 低：信息碎片化、需要与其他文件合并才有价值

## 报告结尾统计

```
## 统计

- 扫描文件数：X
- 保留：X（高 X / 中 X / 低 X）
- 丢弃：X
- 分类分布：C01: X, C02: X, ...（仅列有保留文件的分类）
```
