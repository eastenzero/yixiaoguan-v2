# KB 筛选标准（所有数据源通用）

以下 5 条标准必须**全部满足**，文件才能标记为"保留"：

1. **自包含**：不读其他文档也能理解该段内容
2. **可操作**：至少含一个联系方式、操作步骤、时间地点、具体数值、政策条款
3. **SDFMU 专属**：不是通用常识（"多喝水"不算，"校医院挂号流程"算）
4. **非过期**：不含已明确过期的时效性通知（2024 年及以后的通知仍有参考价值）
5. **非纯新闻**：不是纯事件报道（"我校举办XX活动"类丢弃），除非包含可复用的服务信息

## 特殊判断规则

- 表格模板类（申请表、登记表）：如果包含填写说明则保留，纯空表丢弃
- 通知原文：如果包含流程说明、时间节点、联系方式则提取保留
- 活动预告：如果是常规性活动（每年都有的招聘会、讲座）且含时间地点则保留
- 学生手册类长文：按章节拆分标注，每章独立判断
 纯图片/纯链接页面：丢弃
- 重复内容：如同一目录下 index.md 和 index.htm.md 内容相同，只保留一个，另一个标记为"丢弃（重复）"
