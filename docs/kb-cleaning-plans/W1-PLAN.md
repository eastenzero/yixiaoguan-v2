# W1 原始材料清洗执行规划

> 优先级：中（质量最高但格式复杂，穿插在 W2/W3 间隙处理）
> 数据量：77 个已转换 MD + 211 个未处理原始文件
> 目标产出：按 KB-SPEC V2 规范输出到 `04-output/from-raw/`

---

## 一、数据特征

- 来源：同学和老师提供的原始材料（学生手册、办事指南、表格等）
- 已有 77 个 MD 文件（通过 Word/PDF 转换），分布在 `already-converted/`
- 剩余 211 个未处理文件（89 docx, 50 xlsx, 39 doc, 36 pdf, 31 xls, 5 pptx 等）
- 内容质量高，但很多是表格、表单模板、通知原文，需要判断是否有入库价值
- Excel 类（81 个）处理率 0%，大部分可能是统计表、花名册等无入库价值的文件

---

## 二、处理策略

### 2.1 已转换的 77 个 MD（优先处理）

这些已经是可读文本，让 Kimi 直接扫描筛选。

### 2.2 未处理的 211 个原始文件

分两类处理：
- **文档类（docx/doc/pdf/pptx，共 169 个）**：需要先转为文本再筛选
- **表格类（xlsx/xls，共 81 个）**：大概率是统计表/花名册，先抽样确认是否有价值，如果整体价值低则跳过

### 2.3 图片类（jpg/png，共 16 个）

跳过，纯图片无法提取为 KB 文本。

---

## 三、Kimi 任务设计

### Task W1-1：已转换 MD 扫描分类

**一个 Kimi 任务**，扫描全部 77 个已转换 MD。

```
你的任务是扫描以下目录中的所有 .md 文件，按照知识库入库标准进行筛选和分类。

工作目录：C:\Users\Administrator\Documents\code\kb-pipeline\ws1-raw-materials\already-converted\

筛选标准（必须全部满足）：
1. 自包含：不读其他文档也能理解
2. 可操作：至少含一个联系方式、操作步骤、时间地点、具体数值
3. SDFMU 专属：不是通用常识
4. 非过期：不含已过期的时效性通知
5. 非纯新闻/非纯表格模板：有实际可复用的信息

对每个文件，输出一行：
文件名 | 保留/丢弃 | 分类(C01-C12) | 信息摘要(一句话) | 质量(高/中/低)

特别注意：
- 学生手册类文件可能很长（182页PDF裁切），需按章节拆分标注
- 表格模板类（申请表、登记表）如果包含填写说明则保留，纯空表丢弃
- 通知原文中的流程说明和时间节点可以提取

最后统计：保留 X 个，丢弃 Y 个，各分类数量。

将结果写入：C:\Users\Administrator\Documents\code\kb-pipeline\ws1-raw-materials\processing-output\scan-converted.md
```

### Task W1-2：Excel 抽样评估

先让 Kimi 抽样查看 10-15 个 Excel 文件，判断整体是否有入库价值。

```
你的任务是抽样评估以下目录中的 Excel 文件是否有知识库入库价值。

工作目录：C:\Users\Administrator\Documents\code\kb-pipeline\ws1-raw-materials\原始材料\

请从 xlsx/xls 文件中随机选取 10-15 个，读取内容，判断：
1. 是统计报表/花名册/成绩单 → 无入库价值
2. 是办事流程表/课程安排/时间表/费用标准 → 有入库价值
3. 是表格模板（含填写说明） → 可能有价值

输出：
- 抽样文件清单及判断
- 整体结论：该批 Excel 是否值得全量处理
- 如果值得，预估有效比例

将结果写入：C:\Users\Administrator\Documents\code\kb-pipeline\ws1-raw-materials\processing-output\excel-assessment.md
```

### Task W1-3：KB 草稿生成

对 W1-1 标记为"保留"的文件，合并生成 KB 文档。与 W2-2 使用相同的输出规范。
