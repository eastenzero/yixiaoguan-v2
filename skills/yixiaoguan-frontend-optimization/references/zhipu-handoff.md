# 可直接交给智谱的交接提示

请在当前医小管仓库中使用 `$yixiaoguan-frontend-optimization`，把学生端已经验证的紫色玻璃质感和克制流光交互复用到教师端。

要求：

1. 先检查 `apps/teacher-app` 的真实页面、token、组件和 API，不要凭空重写，也不要改变知识库内容或后端接口。
2. 优先改工作台、学生提问队列、问题详情和知识库页面，保持“待处理问题 → 详情 → 回复/转人工 → 返回队列”的路径连续。
3. 复用已有 token 和图标组件；不要新增图标库，不要引入第三种紫色。默认状态安静，主入口才使用低透明流光；点击时轻微下沉并中断高光。
4. 不在问答顶部显示装饰性的“在线”；只有真实连接状态且有决策价值时才显示。
5. 所有长文本、来源链接、加载/错误/空状态都要在 360px—480px 和桌面宽屏下可读；保留 `prefers-reduced-motion` 降级。
6. 改动前创建 Git 回滚点，完成后运行 `npm run type-check`、`npm run build:h5`、`git diff --check`，再说明提交号和回滚方式。除非我明确要求，否则只改前端，不动后端和知识库。
