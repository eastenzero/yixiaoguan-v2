# 医小管前端视觉与交互基线

这份基线来自当前学生端和教师端真实代码，用于迁移和评审；它不是要求一次性重写整个项目。

## 色彩与 token

当前代码存在两个历史紫色：学生端交互样式大量使用 `#5b2b8f`，教师端 `$primary` 与共享 token 为 `#5b21b6`。迁移时只能选一个作为当前页面的主色，并通过 token 统一，禁止继续增加新的近似紫色。若只改教师端，优先消费教师端已有 `$primary`；若产品决定两端完全同色，再做一次显式 token 迁移并回归学生端。

基础层级：

| 层级 | 推荐表达 |
| --- | --- |
| 页面底 | 暖白/象牙白，避免纯白大面积刺眼 |
| 玻璃表面 | `rgba(255,255,255,.72—.88)` + `blur(18px—26px) saturate(145%—165%)` |
| 边缘 | 透明白高光或主色 10%—20%，不使用厚重描边 |
| 阴影 | 仅悬浮导航、主按钮、弹层使用紫色折射；普通卡片优先用色调差 |
| 正文 | 深紫灰高对比；辅助文案降低透明度但不能低于可读对比度 |

教师端现有 token 位于 `apps/teacher-app/src/styles/tokens.scss`：`$primary`、`$surface`、`$radius-lg`、`$backdrop-bar`、`$elevation-*`。学生端的共享 CSS 变量和玻璃层位于 `apps/student-app/src/styles/theme.scss`、`styles/tokens.scss`。

## 比例、间距与排版

- 移动端内容框保持竖向阅读，使用现有 `--student-frame-max-width: 480px` 和安全区变量，不把页面改成横版。
- 主容器优先采用 8pt 间距；主要卡片使用 20—32px 圆角，按钮与 chip 使用 12—20px 圆角。
- 字体沿用 `Manrope` + `PingFang SC`/`Microsoft YaHei`；中文正文不要用过细字重。
- 教师端桌面可以增加信息列宽，但导航、筛选、列表和详情必须在 360px—480px 窄屏仍可阅读。

## 动效与点击反馈

推荐使用已有的 CSS 能力：

- 默认过渡约 `160ms`，按下时 `translateY(1—2px) scale(.97—.985)`。
- 流光只留给主入口、搜索或主要 CTA；使用宽而低透明度的斜向高光，周期约 7—12 秒。
- 点击时暂停/中断持续流光，补一个 300—520ms 的柔和 sheen 或扩散亮斑，让反馈有因果而非闪烁。
- `@media (prefers-reduced-motion: reduce)` 下关闭循环动画，只保留颜色和位置变化。
- 不使用跳动、强脉冲、过亮霓虹或大面积渐变，避免医疗校园场景显得像营销页。

## 图标与状态

- 学生端的 `AppIcon` 是 CSS 图标系统；教师端已有 `components/icons/` 线性 SVG 组件。优先复用，不混入第三套 icon font。
- 状态文本必须描述真实状态：待处理、处理中、已解决、失败、暂无数据。不要用“AI 在线”代替服务健康检查。
- 加载用局部 skeleton/低幅度进度反馈；错误要给出重试或回到列表的动作；空列表说明下一步。

## 来源与可追溯性

如果页面展示问答来源或知识库条目：标题使用正式中文名称，显示发布单位和日期，链接直接到学校/学院/政府原文。截图只能作为辅助证据，不能替代原文链接；无法确认的内容标为需核验，不要填充虚构政策。
